PyPiPie Shell 2

A Python editor and interactive REPL for pyRevit, built on AvalonEdit — with Revit API autocomplete, signature help and hover tips. It follows Revit's light/dark theme and opens as a modal window, a modeless window or a dockable pane.

AvalonEditRevit API autocompleteREPLModal / Modeless / DockedLight & DarkIronPython 2.7 & 3.4

Opening the shell

Click the PyPiPie Shell button to open it in the last chosen mode. Shift+Click to choose a mode (it is remembered). The settings menu (⚙) also sets the mode for next time.

ModeBehaviourHow code runs
Modeless (default)Floating window; Revit stays usable. Clicking the button again brings the open window forward.Queued through a Revit ExternalEvent and run when Revit is idle.
ModalBlocks Revit until closed.Runs immediately inside the button's command context.
DockedRevit dockable pane that keeps its session for the whole Revit session. Needs an open model.ExternalEvent, like Modeless.
Docked mode needs the pane registered at startup: the extension's startup.py calls register_pypipie_shell(), which calls pypipieshell.register_dockable_pane(). Registration is silent when it works; if it fails, Otto Pilot shows a toast and the traceback goes to the pyRevit log. Restart Revit (or reload pyRevit before opening a model) after installing.

Installing

  1. Copy PyPiPieShell.extension into a folder listed under pyRevit Settings → Custom Extension Directories (or %APPDATA%\pyRevit\Extensions).
  2. Restart Revit so the docked pane can register (a pyRevit reload is enough for the windows).
  3. Use the PyPiPie Shell button on the PyPiPie tab, Shell panel.
  4. Requires pyRevit 7 (it ships AvalonEdit). Older pyRevit: put ICSharpCode.AvalonEdit.dll in lib/pypipieshell/bin.

Getting help

  • Help button on the shell toolbar, or F1 anywhere in the shell.
  • ⚙ settings menu → Help.
  • Shift+Click the ribbon button → Help in the mode picker.
  • Hover the ribbon button and press F1 (pyRevit picks up the help.html in the button bundle).
  • The "AvalonEdit not found" message has an Open Help button; see Troubleshooting below.

Editor

  • Python syntax highlighting (light and dark definitions), current-line highlight, line numbers and code folding for def/class/blocks.
  • Smart indent: a new line after : or an open bracket indents; after return, pass, break, continue, raise it dedents; typing else:, elif, except, finally lines up with the block.
  • Tabs are inserted as four spaces; files are opened and saved as UTF-8 with tabs converted.
  • Every line command (comment, indent, duplicate, move, delete, replace all) is a single undo step.
  • The buffer is autosaved and restored the next time the shell opens (turn off in settings).
  • Ctrl+mouse wheel or Ctrl+=/-/0 zooms all panes.

Autocomplete, signatures, hover

  • Opens after ., after two typed letters, or with Ctrl+Space. Tab/Enter accepts.
  • Members come from .NET reflection on the running Revit API, so they always match your Revit version. Chains resolve through return types: FilteredElementCollector(doc).OfClass(Wall).FirstElement(). lists Element members.
  • Variables are typed from live session values, and statically from x = Type(...), for x in collector:, with ... as x and import ... as x in your code.
  • import / from ... import complete module and namespace names.
  • Typing ( (or Ctrl+Shift+Space) shows every overload with the current argument highlighted.
  • Hovering over a name shows its type, signatures and docs.
  • Nothing is executed to produce completions: instance properties are followed by their declared type, so no Revit getter runs outside API context.

Revit API stubs

Stubs (.pyi) add Python-style signatures and docstrings to completion tooltips, signature help and hover, and module names for import completion. pyRevit ships McNeel's stub generator (pyrevit-stubsbuilder.exe) rather than ready-made stub files, so the shell can build them for you:

  1. Open ⚙ → Build Revit <year> stubs with pyRevit's stubs builder. It runs on RevitAPI.dll and RevitAPIUI.dll of the running Revit and writes to %APPDATA%\pyRevit\PyPiPieShell\stubs\Revit<year>.
  2. Stubs you already have are picked up automatically from common locations (%APPDATA%\RevitAPIStubs, Revit-API-Stubs, the folder above), choosing the subfolder for your Revit version.
  3. Add any other folder with Add stub folder... (for example gtalarico's ironpython-stubs).

The stub index loads in the background and parses each module only when it is needed. Completion lists work without stubs.

Running code

  • F5 or Run runs the whole editor. Ctrl+Enter or Selection runs the selected lines (dedented) or the current line.
  • Editor runs and the REPL share one session: variables, imports and functions persist until Reset session.
  • Before each run the scope is refreshed with doc, uidoc, uiapp, app, active_view and selection (list of selected elements), plus DB, UI, revit, forms, script and from Autodesk.Revit.DB/UI import *.
  • Tracebacks report editor line numbers; the failing line is highlighted. Double-click a File "<editor>", line N line in the output to jump to it.
  • Hold Esc while a script runs to raise KeyboardInterrupt (checked between Python statements; a single long .NET call finishes first). Turn off in settings for maximum speed.
  • In Modeless/Docked mode, a run waits if Revit is busy in a command; Stop cancels it before it starts.

Transactions

ModeWhat happens
AutoCode that does not create its own transactions runs inside one Transaction named "PyPiPie Shell", so model edits work without boilerplate. Code that mentions Transaction, TransactionGroup or SubTransaction runs inside a TransactionGroup (editor) or unwrapped (REPL, so a transaction can span several statements).
GroupEvery run is wrapped in a TransactionGroup: one undo step, rolled back on error. Your code starts its own transactions.
NoneNo wrapping.

Errors roll the run back. If a library call starts its own transaction inside the Auto transaction, the output suggests switching to Group.

REPL (>>> line)

  • Enter runs a complete statement; incomplete ones (ending in :, open brackets) continue on a new line, and an empty line finishes a block.
  • Shift+Enter adds a line, Ctrl+Enter runs regardless.
  • Expression results are printed like the Python REPL.
  • Up/Down browse history (kept between sessions); Esc clears; Ctrl+E focuses the REPL.
  • Autocomplete and signature help work here too.

Theme

The shell follows Revit's Active Theme (Revit 2024+) and switches live when you change it. Colours match pyRevit 7's palette, and the shell publishes them under pyRevit's resource names so pyRevit's control styles look the same. Revit 2021–2023 keep a light UI, so the shell stays light there.

Find & replace

  • All matches are highlighted as you type, with a "3 of 12" counter.
  • Options: match case (Aa), whole word, regular expression (\1 in the replacement inserts group 1).
  • The bar re-flows into rows when the window or pane is narrow, and can be hidden with the magnifier button.

Troubleshooting

SymptomFix
"needs the AvalonEdit editor control"The message lists every path searched. Copy ICSharpCode.AvalonEdit.dll into lib/pypipieshell/bin — one copy on the shared extension covers the whole team. Use a netfx / net462 build for Revit 2024 and older, a net6/net8 build for 2025+. pyRevit 7 ships both under its bin engine folders; Dynamo for Revit also has one.
"docked pane is unavailable" toast at startupSee the pyRevit log for the traceback. The modal and modeless windows still work.
Docked mode opens a window insteadNo model open, or the pane was not registered at startup. Check startup.py and restart Revit.
"Waiting for Revit"Revit is in a command (e.g. a pick). Finish or press Esc in Revit, or click Stop.
Few docstrings in tooltipsBuild or add Revit API stubs (settings menu).
Stub build fails on Revit 2025+The bundled builder targets .NET Framework; add a stub folder generated elsewhere instead.
Loops run slowlyTurn off Esc interrupts running scripts (it uses a trace hook).

Safety

Test on a copy first. The shell runs any Revit API code with your permissions. Try destructive operations (delete, purge, bulk parameter edits) on a detached or copied model.

Auto/Group transaction modes roll back failed runs, but successful runs change the model like any other command — use Revit's Undo ("PyPiPie Shell") to reverse one.
